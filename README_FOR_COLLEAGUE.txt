Транскрибатор — инструкция для запуска у коллеги

1. Распакуйте единственную актуальную сборку в папку без кириллицы и спецсимволов, например:
   C:\Transcriptor

2. Запустите:
   Транскрибатор.exe
   или
   Transcriptor.exe

3. Распознавание:
   - приложение использует только GigaAM-v3 RNNT;
   - поддерживается русская речь;
   - при первом запуске загружается модель примерно на 450 МБ;
   - на CPU обработка работает медленнее, чем на NVIDIA GPU;
   - для каждого слова и реплики сохраняются тайм-коды.

4. GPU:
   - при доступной CUDA приложение использует NVIDIA GPU;
   - иначе включается CPU-режим;
   - активный режим отображается в верхней части окна.

5. Разделение по спикерам:
   - используется pyannote Community-1;
   - доступны режимы Авто, 1, 2, 3, 4 и 4+ участников;
   - если точное число людей известно, выберите его перед обработкой;
   - для первой загрузки моделей нужен HuggingFace-токен.

6. Подготовка HuggingFace:
   - примите условия моделей speaker-diarization-community-1 и segmentation-3.0;
   - укажите собственный HF read-токен в настройках приложения;
   - без HF транскрибация работает, но разделение спикеров отключено.

7. Если Python-зависимости не установлены:
   - запустите resources\setup.bat;
   - скрипт предпочитает Python 3.12;
   - существующая CUDA-сборка PyTorch сохраняется и не заменяется CPU-сборкой.

8. При первом запуске выберите AI-агента:
   - Pi + ChatGPT: выполните /login под своей учётной записью;
   - сторонний API: укажите собственные endpoint, модель и ключ.
   В установщике нет авторизации и ключей разработчика. Пользовательские секреты
   шифруются средствами Windows для текущего профиля.

9. Если нужен Telegram-бот:
   - укажите TELEGRAM_BOT_TOKEN в resources\backend\.env;
   - бот также принимает только русскоязычные записи.

10. Установщик не содержит backend\.env, Pi auth.json или пользовательские ключи.
    Не добавляйте эти файлы вручную перед передачей сборки.

Текущая конфигурация:
- ASR: GigaAM-v3 RNNT;
- диаризация: pyannote Community-1;
- пословные тайм-коды и exclusive-привязка спикеров;
- без резервной или облачной модели распознавания.
