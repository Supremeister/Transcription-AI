# Установка Транскрибатора

Приложение использует одну локальную модель распознавания — **GigaAM-v3 RNNT**. Она предназначена для русской речи. **RUPunct Medium** восстанавливает регистр и пунктуацию, а **pyannote Community-1** разделяет участников.

## Требования

| Компонент | Требование |
|-----------|------------|
| OS | Windows 10 / 11 x64 |
| Python | 3.12 рекомендуется |
| Node.js | 18 или новее |
| FFmpeg | Должен быть доступен в `PATH` для аудио- и видеоформатов |
| RAM | 8 ГБ минимум, 16 ГБ рекомендуется |
| Диск | Не менее 8 ГБ свободного места на время установки |
| GPU | Необязательно; NVIDIA CUDA существенно ускоряет обработку |

При установке Python отметьте **Add Python to PATH**.

## 1. Получить исходники

```powershell
git clone https://github.com/Supremeister/Transcription-AI.git
cd Transcription-AI
```

## 2. Установить Python-зависимости

```powershell
.\setup.bat
```

Скрипт:

- сначала ищет Python 3.12;
- сохраняет уже установленную сборку PyTorch и никогда не заменяет CUDA-вариант CPU-вариантом;
- при отсутствии PyTorch ставит CUDA-сборку на компьютере с NVIDIA или CPU-сборку без NVIDIA;
- устанавливает официальный GigaAM из ревизии upstream `559d88d6b72541412743929f633a6ae7c9950b85`;
- устанавливает `transformers 4.57.6` для RUPunct Medium;
- устанавливает `pyannote.audio 4.x`, PyAV и зависимости Community-1;
- проверяет импорты и доступность CUDA.

Модель GigaAM загружается при первом запуске. Код установки зафиксирован на проверенной ревизии, поэтому повторная установка воспроизводима.

## 3. Настроить HuggingFace

HuggingFace-токен нужен для Community-1 и сегментации длинных записей:

1. Создайте аккаунт на [huggingface.co](https://huggingface.co).
2. Создайте read-токен на [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
3. Примите условия моделей:
   - [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1);
   - [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0).
4. Скопируйте `backend/.env.example` в `backend/.env`.
5. Заполните:

```dotenv
HF_TOKEN=hf_ваш_токен
```

Токен также можно сохранить через настройки приложения.

## 4. Установить интерфейс и backend

```powershell
cd backend
npm install
cd ..\frontend
npm install
npm run build
cd ..\electron
npm install
```

## 5. Запустить

```powershell
cd electron
npm start
```

При первом запуске загрузятся:

- `GigaAM v3 RNNT` — около 450 МБ;
- `RUPunct Medium` — около 340 МБ;
- модели Community-1 и сегментации — около 40 МБ.

Последующие запуски используют локальный кеш. Транскрибация выполняется локально; ключ облачного ASR не нужен.

## Пунктуация, тайм-коды и спикеры

GigaAM формирует слова и их тайм-коды. RUPunct добавляет регистр и знаки препинания к тем же словам. Community-1 назначает спикера словам через exclusive-разметку, после чего приложение собирает их в реплики.

Режимы количества участников:

- `Авто` — от 1 до 6;
- `1`, `2`, `3`, `4` — точное число;
- `4+` — от 4 до 8.

Если число участников известно, точный режим обычно даёт более стабильные подписи. Обычная, не exclusive-разметка используется для отметок одновременной речи.

## GPU

Статус отображается в шапке приложения:

- `GPU (CUDA)` — ускорение активно;
- `CPU` — обработка работает, но занимает больше времени.

Проверка из терминала:

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

Если на компьютере уже установлен рабочий CUDA PyTorch, не устанавливайте поверх него CPU-пакеты.

## AI-анализ

AI-анализ необязателен и не участвует в распознавании.

### Pi Coding Agent

Приложение содержит только безопасную оболочку для запуска Pi. Сам Pi и файл авторизации не упаковываются в Electron-сборку и не публикуются в GitHub.

Установите Pi глобально на каждом компьютере:

```powershell
npm install -g @earendil-works/pi-coding-agent
pi
```

В открывшемся Pi выполните `/login` и выберите ChatGPT Plus/Pro (Codex). Авторизация будет сохранена локально в `%USERPROFILE%\.pi\agent\auth.json`. Не копируйте этот файл в проект и не передавайте его вместе со сборкой.

При анализе приложение запускает Pi в RPC-режиме с флагами `--no-tools`, `--no-extensions`, `--no-skills`, `--no-context-files` и `--no-session`. Транскрипция передаётся выбранной модели; доступ к файлам и Obsidian через этот процесс отключён.

Необязательные настройки находятся в `backend/.env`:

```dotenv
PI_ANALYSIS_PROVIDER=openai-codex
PI_ANALYSIS_MODEL=gpt-5.6-sol
PI_ANALYSIS_THINKING=high
```

Для Groq:

1. Получите ключ на [console.groq.com](https://console.groq.com).
2. Сохраните его в настройках приложения или в `backend/.env`:

```dotenv
GROQ_API_KEY=gsk_ваш_ключ
```

## Telegram-бот

Бот принимает только русскоязычные записи.

1. Создайте бота через [@BotFather](https://t.me/BotFather).

```dotenv

```

## Одна рабочая сборка

```powershell
python -m PyInstaller gigaam_service.spec --noconfirm --clean
npm run build --prefix frontend
npm run pack --prefix electron
```

Команда `pack` создаёт только `dist-exe\win-unpacked`, без второго тяжёлого установщика. Проверяйте эту папку на реальной записи. После успешной проверки храните только рабочую сборку; промежуточные каталоги PyInstaller и старые распакованные версии приложению не нужны.

## Частые проблемы

**Найден не тот Python**

Запустите `setup.bat`: он сначала проверяет стандартные пути Python 3.12. Ручная проверка:

```powershell
py -3.12 --version
```

**GigaAM долго не готова**

Первый запуск загружает примерно 450 МБ. Проверьте интернет и свободное место. Не запускайте одновременно несколько копий приложения.

**Ошибка 401/403 при загрузке моделей**

Проверьте `HF_TOKEN` и убедитесь, что условия обеих моделей pyannote приняты в браузере.

**Диаризация недоступна**

Полностью перезапустите приложение после сохранения токена. Затем проверьте:

```powershell
python -c "import pyannote.audio, av; print('ok')"
```

**CUDA не используется**

Проверьте `nvidia-smi` и команду диагностики PyTorch выше. CPU-режим остаётся рабочим.

**Нужно распознать запись на другом языке**

Текущая сборка предназначена только для русского языка; переключателя на другой ASR нет.
