# Транскрибатор

> Локальная транскрибация русской речи с тайм-кодами, разделением спикеров и необязательным AI-анализом.

## Рабочая сборка

Текущая локальная сборка находится в `dist-exe\win-unpacked\Транскрибатор.exe`. Старые опубликованные релизы не используйте: они предшествуют переходу на GigaAM. При первом запуске приложение загрузит GigaAM-v3 RNNT, RUPunct Medium и модели диаризации — около 850 МБ.

> Настройка Python, GPU и HuggingFace описана в [INSTALL.md](INSTALL.md).

---

## Что умеет

### Транскрибация

- Единственная модель распознавания — **GigaAM-v3 RNNT**, оптимизированная для русской речи.
- **RUPunct Medium** восстанавливает регистр и русскую пунктуацию, не меняя распознанные слова и их тайм-коды.
- Поддерживаются MP3, WAV, OGG, M4A, AAC, MP4, MOV, MKV, AVI и WebM до 500 МБ.
- Для каждого слова сохраняются точные `start` / `end`, а реплики отображаются и экспортируются с тайм-кодами.
- Распознавание выполняется локально: аудио не отправляется в облачный ASR.
- NVIDIA GPU используется через CUDA; без совместимого GPU доступен более медленный CPU-режим.

### Диаризация спикеров

- **pyannote Community-1** определяет, кто и когда говорил.
- Exclusive-разметка сопоставляется с тайм-кодами каждого слова, а обычная разметка сохраняет информацию о перебиваниях.
- Доступны режимы количества участников: `Авто`, `1`, `2`, `3`, `4` и `4+`.
- Для первой загрузки моделей нужен бесплатный HuggingFace-токен.

### AI-анализ

- Поддерживается локальная оболочка **Pi Coding Agent**: приложение запускает установленный Pi в изолированном RPC-режиме без инструментов, расширений, навыков и доступа к файлам.
- Автоматический анализ под тип разговора:
  - **Клиент** — роли, продвижение по воронке, инсайты, следующий шаг и оценка.
  - **Коучинг** — цели, западающие зоны, метрики и динамика.
  - **Своё** — задачи, дедлайны, ключевые мысли и открытые вопросы.
- Поддерживаются Pi, Groq и другие OpenAI-совместимые API.
- AI-анализ необязателен и не влияет на локальное распознавание.

Код оболочки Pi публикуется вместе с приложением, но сам Pi и его авторизация не входят в репозиторий и сборку. На каждом компьютере Pi устанавливается отдельно, а вход выполняется локально. Файл `%USERPROFILE%\.pi\agent\auth.json` остаётся в профиле Windows и исключён из Git.

### Telegram-бот

- Принимает русскоязычные голосовые сообщения, аудио и видео.
- Возвращает транскрипт и, если настроен ключ, AI-анализ.
- Работает, пока десктопное приложение запущено.
- Лимит Telegram Bot API — 20 МБ на файл.

## Быстрый старт из исходников

```powershell
git clone https://github.com/Supremeister/Transcription-AI.git
cd Transcription-AI
.\setup.bat
cd frontend
npm install
npm run build
cd ..\electron
npm install
npm start
```

Рекомендуется Python 3.12. Скрипт сохраняет уже установленную CUDA-сборку PyTorch и не заменяет её CPU-сборкой.

## Стек

| Компонент | Технология |
|-----------|------------|
| Интерфейс | React + Vite + Tailwind CSS |
| Десктоп | Electron |
| Backend | Node.js + Express |
| Транскрибация | GigaAM-v3 RNNT |
| Пунктуация | RUPunct Medium |
| Диаризация | pyannote speaker-diarization-community-1 |
| GPU | PyTorch + CUDA |

| Telegram | python-telegram-bot |

## Структура проекта

```text
├── backend/
│   ├── src/                   # Node.js API
│   ├── gigaam_service.py      # GigaAM + RUPunct + Community-1 HTTP-сервис
│   └── test_gigaam_service.py # Тесты пунктуации, тайм-кодов и спикеров
├── frontend/                  # React-интерфейс
├── electron/                  # Electron и упаковка приложения
├── telegram_bot.py            # Русскоязычный Telegram-бот
├── setup.bat                  # Python 3.12, GigaAM и Community-1
└── gigaam_service.spec        # Сборка локального Python-сервиса
```
